3. BACKGROUND TASK PATTERNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Global Registry: DATA_TASKS (dict) + DATA_TASKS_LOCK (threading.Lock)
  Location: viewer/app.py lines 2177-2178
  
  Task Creation: _create_task_record(task_id, name, description, kind, source,
                                      total_items, log_file, control_mode, ...)
    ├─ Status: "starting" → "running" → ("completed"|"failed"|"cancelled")
    ├─ Progress: percent (0–100%), detail (completed, failed, total, current)
    ├─ Control: pause_event, stop_event (threading.Event)
    ├─ Log: TASK_LOGS_DIR / f"task_{task_id}.log"
    └─ Timestamps: created_at, updated_at
  
  Logging: _write_task_log_line(handle, task_id, message, stream, log_level)
    → Writes to file AND ingests to progress
    → ✅ prefix: increments detail["completed"]
    → ❌ prefix: increments detail["failed"]
    → Auto-calculates percent = completed / (completed+failed) * 100
  
  Threading Pattern (from download_data, line 2641):
    1. task_id = uuid.uuid4()
    2. record = _create_task_record(task_id, ..., log_file=task_log)
    3. DATA_TASKS[task_id] = record (thread-safe)
    4. def run_task():
         _set_task_status(task_id, "running")
         [do work, log progress]
         _set_task_status(task_id, "completed")
    5. thread = threading.Thread(target=run_task, daemon=True)
    6. thread.start()
    7. return {"task_id": task_id}, 202
  
  Control Endpoints (reusable):
    POST /api/data/tasks/<task_id>/pause
    POST /api/data/tasks/<task_id>/resume
    POST /api/data/tasks/<task_id>/cancel
    GET  /api/data/tasks/<task_id>/logs
  
  Serialization: _serialize_task(task_id, task, include_log=True, max_log_bytes)
    → JSON-safe dict with id, name, status, progress, controls, logs

6. CRITICAL GOTCHAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  A. Date Range Splitting
     • _detect_date_range() returns INTERSECTION for multi-symbol [cli.py:54-84]
     • Ensure train/test splits valid before calling engine
  
  B. Parameter Serialization
     • BacktestConfig.parameters: dict[str, Any] must be JSON-safe
     ✗ {"threshold": np.float64(0.5)}  # Not serializable
     ✓ {"threshold": float(0.5)}       # OK
  
  C. Result Serialization
     • BacktestResult.save() → full JSON (can be large)
     • Consider: store only best-trial results fully; stats summary for others
  
  D. Multi-Symbol Handling
     • ProcessPoolExecutor merges trades from all symbols
     • Trade IDs renumbered after merge [vectorbt_adapter.py:317-319]
     • Each symbol processed independently, then merged
  
  E. Stop/Pause Signals
     • Check: if task["stop_event"].is_set(): raise CancelledError()
     • Wait:  if task["pause_event"].is_set(): task["pause_event"].wait()
     • Can integrate with Optuna callbacks for graceful stopping
  
  F. API/Frontend Contract
     • Required stats: sharpe, sortino, cagr, max_drawdown_pct, win_rate,
       profit_factor, psr, p_value
     • Use: compute_stats_for_result(result) from runner/stats.py
  
  G. Intrabar Modeling
     • VectorbtAdapter loads extra data if modeling_resolution != "open_close"
     • Performance cost per trial; disable for speed

    from runner.engines.base import BacktestConfig
    config = BacktestConfig(strategy_name="test", symbols=["AAPL"],
                            timeframe="1h", start_date="2023-01-01",
                            end_date="2023-12-31", parameters={"param1": 10})
    engine = VectorbtAdapter()
    result = engine.run(config, "/path/to/strategy.py")

    from runner.stats import compute_stats_for_result

    # Populates result.stats with sharpe, cagr, max_drawdown, etc.
  
  Create Task:
    import uuid
    task_id = str(uuid.uuid4())
    task_log = TASK_LOGS_DIR / f"task_{task_id}.log"
    record = _create_task_record(task_id, name="Optimize mean_reversion",
                                  description="HPO with Optuna...",
                                  kind="optimization", source="viewer",
                                  total_items=50, log_file=task_log,
                                  control_mode="thread", supports_control=True)
    with DATA_TASKS_LOCK:
